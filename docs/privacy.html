개인정보처리방침

시행일: 2026년 7월 29일

MicroZed(이하 "앱")는 개인 개발자 ATMnou가 만든 개인 프로젝트입니다. 별도의 운영 회사나 법인이 없으며, 이 문서에서 "개발자"는 ATMnou를 가리킵니다.

이 문서는 앱을 사용할 때 어떤 정보가 어떻게 저장·처리되는지 설명합니다.

1. 요약

  • 앱은 자체 서버를 운영하지 않습니다. 개발자는 사용자의 대화 내용, 캐릭터, 플롯 등 어떤 데이터도 수집·저장·열람할 수 없습니다.
  • 모든 데이터(플롯, 캐릭터, 대화 기록, 로어북, 프로필, 이미지, 설정 등)는 기기에만 저장됩니다.
  • 사용자가 직접 등록한 AI API 키(BYOK, Bring Your Own Key)로 원격 AI 모델을 사용하면, 그 대화 내용은 사용자가 선택한 제3자 AI 제공자(OpenAI 호환 API 등)에게 전송됩니다. 이는 개발자가 아니라 해당 제공자의 개인정보 처리 방침이 적용됩니다.
  • 기기에 내장된 로컬 LLM(오프라인 모델)을 쓰면 대화 내용이 기기 밖으로 전혀 나가지 않습니다.
  • 광고, 사용자 추적(트래킹), 분석(analytics) SDK를 포함하지 않습니다.

2. 앱이 저장하는 정보

앱은 다음 정보를 기기 로컬 저장소(SQLite 데이터베이스 및 로컬 파일)에만 저장합니다.

  • 플롯, 캐릭터, 인트로, 로어북 등 사용자가 직접 작성한 콘텐츠
  • 대화 세션 및 대화 기록(채팅 메시지)
  • 대화 프로필(플레이하는 유저를 나타내는 이름·이미지·소개)
  • 캐릭터/커버/프로필 이미지 파일
  • AI 프리셋 설정(이름, Base URL, 모델명, 온도 등 요청 파라미터)
  • API 키: 원문은 Windows에서는 DPAPI(운영체제 제공 암호화)로, 그 외 플랫폼에서는 앱 전용 저장 공간에 보관됩니다. 이 키는 오직 사용자가 등록한 AI 엔드포인트에 요청을 보낼 때만 사용됩니다.
  • 언어/이미지 표시 방식 등 앱 환경설정
  • (선택) 다운로드한 로컬 LLM 모델 파일(용량이 커서 기기 저장소에 별도 캐시됨)

이 정보들은 마이페이지의 "전체 저장/전체 불러오기" 기능으로 사용자가 직접 zip 파일로 내보내거나 복원할 수 있으며, "전체 초기화" 기능으로 언제든 완전히 삭제할 수 있습니다.

3. 정보가 외부로 전송되는 경우

개발자가 운영하는 서버는 존재하지 않으므로, 개발자에게 직접 전송되는 정보는 없습니다. 다만 앱의 기능을 사용하는 과정에서 아래와 같이 사용자 본인이 선택한 제3자에게 데이터가 전송될 수 있습니다.

  • 원격 AI 프리셋 사용 시: 대화 내용(시스템 프롬프트, 대화 기록, 사용자 입력)이 사용자가 등록한 Base URL(예: OpenRouter, OpenAI 호환 엔드포인트 등)로 전송됩니다. 어떤 서비스를 쓸지, API 키를 무엇으로 할지는 전적으로 사용자가 결정합니다.
  • 추천 로컬 모델 다운로드 시: 모델 파일을 받기 위해 Hugging Face(huggingface.co) 서버에 접속합니다. 이때 다운로드 요청 자체(IP 주소 등 통신에 필요한 최소 정보)는 Hugging Face 측에 전달되며, 이는 Hugging Face의 정책을 따릅니다.
  • 로컬 LLM 사용 시: 모델을 한 번 내려받은 뒤에는 추론이 전부 기기 안에서 이루어지고, 대화 내용은 기기 밖으로 전송되지 않습니다.

이 외의 경우, 즉 앱을 오프라인으로 로컬 LLM만 사용하거나 데이터를 입력·열람만 하는 경우에는 어떤 정보도 기기 밖으로 나가지 않습니다.

4. 정보 보관 기간

모든 데이터는 사용자가 앱을 삭제하거나, 앱 내 "전체 초기화"를 실행하거나, 개별 항목(플롯/캐릭터/프리셋 등)을 삭제할 때까지 기기에 보관됩니다. 개발자는 이 데이터에 접근할 수 없으므로 별도로 삭제를 요청할 필요가 없습니다.

5. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동으로부터 개인정보를 의도적으로 수집하지 않습니다.

6. 이 방침의 변경

앱 기능이 추가되거나 바뀌면 이 문서도 함께 업데이트될 수 있습니다. 변경 시 이 파일의 시행일이 갱신됩니다. 별도의 이메일 통지 등은 제공되지 않으니, 궁금한 점이 있으면 아래 연락처로 문의해 주세요.
